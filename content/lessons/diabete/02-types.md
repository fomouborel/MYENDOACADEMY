# Diabète de type 1, de type 2 et LADA : reconnaître et typer

:::archives
**Ce que les archives interrogent sur ce thème** (35 questions)

- **Type 1 au diagnostic : ce qui n'est pas présent** (6 questions) : **complications microangiopathiques**, **ferritine augmentée**, **peptide C nul**. Présents : âge inférieur à 30 ans, poids normal, **cétose**, amaigrissement récent, anticorps **anti-GAD**, polyurie et polydipsie.
- **Type 1 : vrai et faux** :
  - la phase de **rémission (« lune de miel »)** est **toujours transitoire** ; les symptômes apparaissent **brutalement**, souvent à l'occasion d'un événement ;
  - l'hyperglycémie apparaît quand environ **80 %** des cellules bêta sont détruites ; il peut survenir chez la **personne âgée** ;
  - faux : « 75 % de risque si les deux parents sont atteints », « toujours une acidocétose au début », « le diabète apparaît dans les semaines qui suivent les anticorps ».
- **Type 2 au diagnostic : ce qui n'est pas présent** : **début brutal**, **acidocétose**, « anticorps anti-adipocytes », ferritine diminuée. Présents : surcharge pondérale, plus de 40 ans, absence de cétose spontanée, parfois **rétinopathie** ou **coma hyperosmolaire** d'emblée.
- **Facteurs favorisants du type 2** : hérédité, sédentarité, surpoids, **retard de croissance intra-utérin**, ovaires polykystiques, syndrome métabolique. Faux : alcoolisme chronique, oreillons, « perte de cellules bêta » comme facteur, « BMI inférieur à 25 exclut le diagnostic », « rarement d'histoire familiale ».
- **Typer un diabète** (5 questions) : anticorps anti-GAD, peptide C, HOMA, poids maximal, autres maladies auto-immunes. **Pas l'HbA1c.**
- **LADA** : diabète **auto-immun de l'adulte** ; traitement : **insuline**.
- **Anatomie pathologique** (Marbaix, 7 questions) : type 1 ancien = îlots **en place**, mais **plus d'insuline (pro-insuline) détectable** ; **pas** de dépôt amyloïde. Type 2 = **dépôts amyloïdes**, pas de biopsie pour le diagnostic.
:::

## 1. Les deux grands types

| | **Type 1** | **Type 2** |
|---|---|---|
| Mécanisme | **destruction auto-immune** des cellules bêta : **carence absolue** en insuline | **insulinorésistance** + défaut **progressif** de sécrétion |
| Âge | souvent **moins de 30 ans**, mais **à tout âge** (y compris chez la personne âgée) | souvent **plus de 40 ans**, de plus en plus de jeunes |
| Poids | **normal ou bas**, **amaigrissement** récent | **surpoids** ou obésité abdominale (un IMC normal ne l'exclut pas) |
| Début | **brutal** (jours, semaines), souvent après un événement (infection) | **insidieux**, souvent **asymptomatique**, découvert par hasard |
| Cétose | **fréquente** ; l'acidocétose peut être inaugurale, mais **pas toujours** | **pas de cétose spontanée**, sauf insulinopénie très sévère |
| Complications au diagnostic | **absentes** (elles demandent des années) | **possibles d'emblée** (rétinopathie), car le diabète évoluait sans bruit ; coma hyperosmolaire possible |
| Anticorps | **anti-GAD**, anti-IA2, anti-ZnT8, anti-insuline | **négatifs** |
| Peptide C | bas, encore souvent dosable au début ; **indosable** après des années | normal ou élevé, puis diminue |
| Hérédité | **la plupart des patients n'ont pas d'antécédent familial** ; risque pour l'enfant de quelques pour cent si un parent est atteint | **histoire familiale fréquente** |
| Maladies associées | **auto-immunes** : thyroïdite, **Addison**, maladie cœliaque, vitiligo | **syndrome métabolique** (fréquent), stéatose |

## 2. Le diabète de type 1

**Histoire naturelle** :
1. **Prédisposition génétique** (HLA) et facteur déclenchant.
2. Apparition des **anticorps**, souvent **des mois ou des années** avant le diabète.
3. Destruction progressive des cellules bêta. L'**hyperglycémie** apparaît quand il n'en reste qu'environ **10 à 20 %** (environ **80 %** détruites).
4. Après le début de l'insuline, une **rémission partielle (« lune de miel »)** est possible : les besoins en insuline diminuent. Elle est **toujours transitoire**.

**Syndromes polyendocriniens auto-immuns** :
- **type 1** (enfant) : **hypoparathyroïdie**, **Addison**, candidose ; le diabète de type 1 peut s'y associer ;
- **type 2** (adulte, le plus fréquent) : **Addison**, thyroïdite auto-immune, **diabète de type 1**.

**Amaigrissement d'un diabétique de type 1** : insulinopénie (oubli d'insuline, diabète déséquilibré), **hyperthyroïdie** ou **Addison** associés, maladie cœliaque, **amyotrophie diabétique (syndrome de Garland)**. Une néphropathie avec protéinurie fait plutôt **gonfler** (œdèmes) que maigrir.

## 3. Le diabète de type 2

- **Mécanisme** : insulinorésistance (muscle, foie, tissu adipeux), puis **épuisement progressif** des cellules bêta ; hyperglucagonémie ; **effet incrétine diminué** (et non augmenté).
- **Facteurs de risque** : hérédité (histoire familiale fréquente), sédentarité, surpoids et graisse abdominale, **retard de croissance intra-utérin** et malnutrition fœtale, antécédent de diabète gestationnel, ovaires polykystiques, syndrome métabolique (une grande majorité des diabétiques de type 2 en ont un).
- **Évolution** : le diabète peut **régresser** avec une perte de poids importante (régime, chirurgie bariatrique).
- Une **chirurgie** ou une maladie aiguë sévère peut nécessiter une **insuline transitoire**.

## 4. Le LADA

Le **LADA** (*latent autoimmune diabetes in adults*) est un diabète **auto-immun de l'adulte** (souvent après 30 ou 35 ans) :
- il ressemble d'abord à un type 2 (pas d'insuline nécessaire au début) ;
- les **anticorps anti-GAD** sont **positifs** ;
- l'insulinopénie s'installe en quelques mois à années : le traitement repose sur l'**insuline**, y compris chez la personne âgée.

## 5. Typer un diabète

| Outil | Ce qu'il apporte |
|---|---|
| **Clinique** | âge, IMC, **poids maximal** atteint dans la vie, rapidité du début, cétose, histoire familiale, **autres maladies auto-immunes** |
| **Anticorps** anti-GAD (et autres) | **fortement positifs** : en faveur d'un type 1 ou d'un LADA |
| **Peptide C** | réserve de sécrétion d'insuline |
| **Test HOMA** | à partir de la glycémie et de l'insuline **à jeun** : estime **la fonction des cellules bêta et la sensibilité à l'insuline** |
| **HbA1c** | **ne type pas** le diabète : elle mesure seulement l'équilibre |

**Situation des archives** : un homme de 70 ans, IMC de 32, glycémie à 300, **cétonurie** importante, pH à 7,3, altération de l'état général. Malgré l'âge et le poids, la **cétose** fait doser les **anticorps** (LADA, type 1) et chercher une **cause pancréatique** (cancer) devant l'altération de l'état général. On ne le renvoie pas à domicile sous metformine.

## 6. Anatomie pathologique du pancréas (Marbaix)

| | Type 1 **au début** | Type 1 **ancien** | Type 2 |
|---|---|---|---|
| Îlots de Langerhans | **insulite** (infiltrat lymphocytaire) | **toujours en place**, petits | en place |
| Cellules bêta | en cours de destruction | **disparues** : plus de marquage de l'insuline ni de la **pro-insuline** ; les autres cellules (alpha, delta) persistent | diminuées |
| Dépôts amyloïdes | non | **non** | **oui** (amyline ; rouge Congo, biréfringence en lumière polarisée) |

Une **biopsie n'est jamais nécessaire** pour diagnostiquer un diabète.

## 7. À retenir

- **Type 1** : auto-immun, brutal, cétose, amaigrissement, jeune (mais tout âge), anticorps anti-GAD ; **pas de complications au diagnostic** ; rémission transitoire possible ; maladies auto-immunes associées.
- **Type 2** : insidieux, surpoids, plus de 40 ans, **histoire familiale fréquente** ; complications parfois présentes d'emblée ; pas de cétose spontanée ; effet incrétine diminué.
- **LADA** : auto-immun de l'adulte, anti-GAD positifs, **insuline**.
- **Typer** : clinique, anticorps, peptide C, HOMA. **Jamais l'HbA1c.**
- **Anatomie pathologique** : type 1 ancien = îlots présents sans insuline ; type 2 = amyloïde.

### Pièges classiques

- **« Complications microangiopathiques au diagnostic d'un type 1 »** : non.
- **« Les deux parents diabétiques de type 1 : 75 % de risque »** : non, bien moins.
- **« Le type 1 débute toujours par une acidocétose »** : non.
- **« Un IMC inférieur à 25 exclut un type 2 »** : non.
- **« Disparition des îlots » dans le type 1 ancien** : non, ce sont les cellules bêta qui disparaissent.

### Attention : corrections discutées dans les archives

- **`ND-maiter-diabete-Q37`** (amaigrissement du type 1) : la compilation retient « néphropathie avec macroprotéinurie » comme la cause qui ne fait pas maigrir. Le raisonnement se défend (la néphropathie donne plutôt des œdèmes), mais le syndrome néphrotique sévère peut s'accompagner d'une fonte musculaire. Signalée « discutée ».

### Questions de compréhension

<details><summary>Pourquoi un diabétique de type 2 peut-il avoir une rétinopathie dès le diagnostic, et pas un type 1 ?</summary>
Le type 2 évolue souvent pendant des années sans symptôme avant d'être découvert : les complications ont eu le temps de s'installer. Le type 1 se révèle brutalement, peu de temps après le début de l'hyperglycémie.
</details>

<details><summary>Une femme de 45 ans, mince, est traitée depuis un an pour un « type 2 » qui se déséquilibre malgré la metformine. Que doser ?</summary>
Les anticorps anti-GAD, à la recherche d'un LADA. S'ils sont positifs, l'insuline sera nécessaire.
</details>

<details><summary>Pourquoi l'HbA1c ne permet-elle pas de typer un diabète ?</summary>
Elle reflète seulement la glycémie moyenne des derniers mois, quel que soit le mécanisme du diabète. Un type 1 et un type 2 également mal équilibrés ont la même HbA1c.
</details>
